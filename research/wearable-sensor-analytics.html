Overview

The task

Use EMG and knee-angle data to measure muscle activation during each repetition.

My contribution

Cleaned signals, detected reps, extracted features and compared baseline models.

The result

Per-repetition summaries and a repeatable pipeline, with test results and limits documented.

Technical notes & decisionsPreprocessing, validation and model results

From files to features

Built flexible loaders for inconsistent delimiters, headers and decimal formats. Cleaned and filtered EMG, then used the knee-goniometer channel to find repetition boundaries. Computed activation metrics per repetition and extracted features in 200 ms windows with a 50 ms hop.

The decisions that mattered

  • Robust normalisation: used the 95th percentile instead of the single maximum. Without MVC calibration, the output is relative activation, not a clinical percentage.
  • Adaptive rep detection: smoothed the knee angle with Savitzky-Golay and checked peaks against movement, rather than relying on one fixed threshold.
  • Baselines first: compared threshold rules, Logistic Regression, KNN, SVM and Gradient Boosting before choosing a multi-muscle Random Forest.
  • Subject-aware evaluation: used leave-one-subject-out validation so overlapping windows from one person couldn't make a random split look better than it was.

Results and limits

Prepared test-set R²: RF 0.967, VM 0.959, BF 0.949, ST 0.915. MAE: 2.75, 2.80, 2.83 and 3.05 on the processed activation scale. These describe that dataset and split, not a guarantee for a new athlete or new hardware.

Next steps: collect MVC calibration, validate on new athletes and exercises, and add uncertainty estimates. This is an analytics foundation, not a medical or diagnostic product.

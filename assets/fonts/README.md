# Local web fonts

Sora (headings) and DM Sans (body and controls) are served locally as Latin-subset variable WOFF2 files. Their SIL Open Font License files are included beside them.

Sources, retrieved 19 October 2026:

- https://github.com/google/fonts/tree/main/ofl/sora
- https://github.com/google/fonts/tree/main/ofl/dmsans

The official variable TrueType sources were converted with FontTools, retaining layout features and weight variation. No third-party font request is needed when visiting the site.

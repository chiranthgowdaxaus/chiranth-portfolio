# Selected work blueprints

Original SVG drawings for the portfolio's light-paper, dark-ink and orange palette.

- `paidly-blueprint.svg`: bill, calendar and recurrence arrows.
- `repway-blueprint.svg`: dumbbell and repetition path.
- `sensor-blueprint.svg`: four illustrative signal channels.
- `crowd-blueprint.svg`: stadium plan and illustrative density dots.

Conceptual cover art only, not screenshots, measured data, hardware designs or real venue readings. App detail pages use labelled native web recreations with sample data instead of screenshots. The stadium's seating dots are illustrative, not an attendance estimate. Covers are decorative where card text already describes each project.

# Blue blueprint backgrounds

Decorative artwork supporting the selected ink-blue portfolio direction. These are transparent backgrounds behind real HTML content, not page screenshots. The portrait, logos, buttons and copy remain independent elements.

## Hero

- Runtime asset: `blueprint-hero-blue.webp`
- Native dimensions: 2009 x 783
- Created using built-in image generation with transparent background, then losslessly converted to WebP.
- Prompt direction: thin muted-blue blueprint phone with an overlapping checklist card, curved arrows, measurements and faint drafting marks. Leave the left and centre open for the original portrait and live heading. No readable text, photos, logos, filled backgrounds or orange. Place the phone near the right-centre rather than at the outer edge.

## Sections

- Runtime asset: `blueprint-sections-blue.webp`
- Dimensions: 1440 x 480
- Created using built-in image generation with transparent background, then losslessly converted to WebP.
- Prompt direction: a connected blue-pencil chart, website wireframes and tilted phone study with pale broken drafting grids and measurement ticks. Open, low-contrast line art for use behind HTML. No text, photos, logos, filled panels or orange.

The lossless PNG generation sources are retained locally and ignored by Git. Runtime images preserve alpha. CSS controls size and repetition. At the user's request, artwork is faint and lightly blurred, with an additional fade behind the hero copy, quieter small-screen backgrounds and no duplicate layering in the contact section. Text and controls remain sharp.

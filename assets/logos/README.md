# Tool logo sources

- Python, Figma, Swift, React, TypeScript, pandas, NumPy, scikit-learn, Matplotlib, Git, Illustrator and Photoshop: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons). Original SVG variants. MIT license in DEVICON-LICENSE.txt.
- SciPy: original logo from the [official press kit](https://scipy.org/press-kit/), self-hosted unchanged from [scipy.org](https://scipy.org/images/logo.svg) to identify the project tool.
- Power BI: [Microsoft PowerBI-Icons](https://github.com/microsoft/PowerBI-Icons/blob/main/SVG/Power-BI.svg). Original SVG, unchanged. Microsoft attribution and CC BY 4.0 license in POWERBI-LICENSE.txt.
- SQL: original generic database symbol. SQL is a language, not a specific database vendor; this icon does not imply a vendor certification.
- The Swift logo identifies the Swift/SwiftUI toolchain. Brands belong to their respective owners and are shown only to identify skills, not imply endorsement.

Logos are self-hosted. Labels remain available to screen readers, keyboard focus and hover.
